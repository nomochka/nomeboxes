# NomeBoxes

Плагин рюкзаков для Paper 1.21.11. Автор: **nome**.

Рюкзаки — кастомные предметы со своей текстурой (через компонент `item_model`,
работает на 1.21.4+). По ПКМ рюкзак открывается, содержимое сохраняется автоматически
(файл `plugins/NomeBoxes/backpacks.yml`).

## Виды рюкзаков

| Тип | Название | Слотов |
|-----|----------|--------|
| `small` | Малый | 9 |
| `medium` | Средний | 27 |
| `large` | Большой | 45 |
| `super` | Супербольшой | 54 |

## Сборка

Нужен JDK 21 и Maven:

```
mvn package
```

Готовый jar: `target/NomeBoxes-1.0.0.jar` — положить в папку `plugins/`.

## Ресурспак (текстуры)

В папке `resourcepack/` лежит готовый ресурспак с плейсхолдер-текстурами:

- заменить картинки в `resourcepack/assets/nomeboxes/textures/item/*.png` на свои (16x16);
- пересобрать zip: `powershell -File scripts/build-resourcepack.ps1` → `NomeBoxes_ResourcePack.zip`.

Выдать пак игрокам:
- одиночка/LAN: кинуть zip в `.minecraft/resourcepacks`;
- сервер: загрузить zip на хостинг и указать URL в `server.properties`
  (`resource-pack=` и опционально `resource-pack-sha1=`), либо использовать плагин типа
  "ResourcePackManager".

Без ресурспака предмет будет выглядеть как фиолетово-чёрная «сломанная» модель — это нормально,
пока текстура не подключена.

## Команды

```
/nomeboxes give <small|medium|large|super> [игрок]   (алиас /nbx)
```

Принимаются и русские названия: `малый`, `средний`, `большой`, `супер`.

## Права

- `nomeboxes.give` — выдача рюкзаков (по умолчанию только операторы).

## Механика

- ПКМ (в любой руке, по воздуху/блоку/сущности) — открыть рюкзак.
- Установка как блока заблокирована.
- Содержимое привязано к уникальному ID предмета и живёт в `backpacks.yml`,
  автосохранение каждые 10 секунд + при выключении сервера.
- Копия рюкзака не дублирует вещи — обе копии смотрят в один контейнер по ID.
